# Data Anonymizer API (VK Task)

Микросервис для автоматической маскировки чувствительных персональных данных (PII) в текстах. Проект создан в качестве портфолио при переходе в отдел QA/Application Security.

## 🚀 Стек технологий
* **Python 3** + **FastAPI** (веб-фреймворк)
* **Docker** (контейнеризация)
* **Pytest** (автоматизированное тестирование)
* Регулярные выражения (RegEx) для поиска паттернов данных

## 🛡️ Безопасность
Доступ к API защищен обязательной передачей секретного ключа в заголовке `X-API-Key`. Пароли и ключи не хранятся в открытом виде. При отсутствии или несовпадении ключа сервис отдает ошибку `401 Unauthorized`.

## ⚙️ Как запустить проект

**Через Docker:**
1. Собрать образ: `docker build -t anonymizer-app .`
2. Запустить контейнер: `docker run -d -p 8000:8000 anonymizer-app`

После запуска документация (Swagger) будет доступна по адресу: `http://localhost:8000/docs`

## ✅ Автотесты
Проект покрыт автотестами (Pytest), проверяющими:
- Позитивный сценарий (успешная маскировка данных при правильном ключе)
- Негативный сценарий (отказ в доступе при попытке несанкционированного запроса)
Запуск тестов: `pytest test_main.py`
